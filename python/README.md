# Python Prototype Components

These folders are placeholders for the agentic research harness. They do not implement LLM calls, MCP tools, workload execution, or failure injection in the initial milestone.

- `llm-agent`: future baseline agent entry point.
- `mcp-server`: future MCP tool facade.
- `workload-generator`: future deterministic experiment workload generator.
- `failure-injector`: future controlled failure injection utilities.

Each component currently has a tiny `main.py` so scripts can be wired into later experiments without changing the repository layout.
